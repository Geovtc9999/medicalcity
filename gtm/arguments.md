« Démo sur **jeu synthétique**. Un vrai dossier = DPA + base légale. On ne suicide pas le Trust pour un théâtre de 20 minutes. »

## Structure d’un devis (une page)

1. Objet (SKU + une phrase)  
2. Périmètre **inclus** (3 puces)  
3. Exclusions (données nominatives, SLA 24/7, robot, HDS, claims)  
4. Prix HT / TVA / échéances  
5. Durée / propriétaire IP (le client possède *ses* données ; MedicalCity possède le logiciel)  
6. HITL : rien n’est décision publique sans humain
