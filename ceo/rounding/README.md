# Rounding Président

Une demi-page par contact. Pas de donnée de santé nominative.

Quota : **1 / semaine**. Rotation : aidant → EHPAD/SAD → instructeur APA → opérateur → clinicien.

## Modèle

- Date / lieu / fonction de l’interlocuteur (pas le nom du bénéficiaire)
- Question posée : « Qu’est-ce qui cassera au premier dossier réel ? »
- 3 verbatims max
- 1 risque Trust (claim, consentement, responsabilité)
- 1 ticket GTM ou OPS
- Ce que le Président a promis (rien, ou une date)

Les tickets sortent vers CARE / GTM / OPS. Le fichier reste ici comme mémoire de terrain (Mayo : ce que les dashboards ne voient pas).
