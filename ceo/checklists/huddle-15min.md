**Tous les jours ouvrés, 07:30 Paris. Debout. Pas de slides.**  
Présents : Président, OPS, PLAT, CARE (AGE facilité). Sreypov si P1 Care.

## Règles

- On ouvre par la sécurité, **jamais** par le deck ou LinkedIn.
- Ce qui est résolu au niveau siège **ne se raconte pas**.
- Données de santé : volumes, incidents, schémas — **jamais** un nom.
- Si P0 : fin du huddle, OS cassé, cellule incident (CARE + OPS + Président).
- AGE écrit 8 lignes dans le standup du jour. Pas un CR de 2 pages.

## Phrase interdite

« On en reparlera au Comex. »  
Si c’est rouge, c’est **aujourd’hui**. Le Comex est pour les arbitrages de 12 sujets, pas pour les P1.
